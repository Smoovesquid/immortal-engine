## HEADLINE — invented-id count: 0 (PASS)

An invented id is any target/object the LLM proposed that does not exist in the
scene candidate bundle. This benchmark counts them on the RAW proposal, before
grounding runs — grounding then hard-rejects every one, so 0 should ALSO reach
`playerMove` labeled `source:'llm'` regardless of this count. A non-zero count here
is a signal about the model's proposal quality, not a live safety gap (grounding
is the safety gate, and it is unconditionally applied).

## Notes

- Corpus seeded from real gate-history failing turns cited in docs/PACKETS.md INT-2
  and docs/briefs/INT-2-llm-translator-sonnet.md (referent ambiguity, compound asks,
  impossible actions, grounded/ungrounded targets).
- The parser-only baseline never calls a network — it is `engine/intent/parseIntent.js`
  run directly against the same bundle, for comparison.
- This script is NOT part of `node --test` by design (network calls do not belong in the
  fast loop) — run it explicitly: `node scripts/intent-eval.mjs`.
- **Pre-existing bug found while running this benchmark (not introduced by INT-2):**
  `server/llmProvider.js`'s hardcoded `ANTHROPIC_DEFAULT_MODEL = 'claude-sonnet-4-20250514'`
  404s against the live Anthropic API (verified directly). This run used the existing
  `LLM_MODEL` env override (`LLM_MODEL=claude-sonnet-4-6`, matching `engine/llmAdapter.js`'s
  working default) to work around it. Any other code path relying on
  `server/llmProvider.js`'s bare default (no `LLM_MODEL` override) is silently broken
  right now — flagged for a follow-up packet, out of scope for INT-2's allowed_files.
- **Ollama scored 0% packet-match, but not from invented ids** — it returned valid JSON
  every time, just with non-canonical verb tokens (e.g. `"stab"` instead of the
  vocabulary's `"attack"`). `makeIntent()` correctly normalizes any verb outside
  `intentSchema.js`'s 10-verb enum to `'ask'` (Purity Rule: no parallel contract enum) —
  so this is grounding doing its job, not a bug. It does mean the 8B local model needs a
  stricter prompt (explicit enum enumeration, few-shot) before it's a serious seat
  candidate; the Anthropic backend already receives the enum in its schema hint and
  matched cleanly.
